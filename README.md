## How to run

### 1. Clone the repository

\`\`\`bash
git clone https://github.com/camillylimaf/linux-system-monitor.git
\`\`\`

### 2. Enter the project directory

\`\`\`bash
cd linux-system-monitor
\`\`\`

### 3. Give execution permission

\`\`\`bash
chmod +x monitor.sh
\`\`\`

### 4. Run the monitor

\`\`\`bash
./monitor.sh
\`\`\`
